# Certificates Directory

This directory contains documentation related to TLS and mutual TLS (mTLS) certificates used by the Spring Security application.

## Purpose

The application uses mTLS to authenticate clients connecting to the HTTPS server.

During the TLS handshake:

1. The server presents its server certificate.
2. The client validates the server certificate against its trusted CA.
3. The server requests a client certificate.
4. The client presents its certificate.
5. The server validates the client certificate against its configured truststore.
6. The TLS connection is established only if certificate validation succeeds.

## Certificate Generation

Use the script:

```bash
bash scripts/generate-mtls-certs.sh
```

The script generates the local development CA, server certificate, client certificate, and PKCS12 keystores.

## Generated Certificate Location

Generated files are stored under:

```text
secrets/
├── ca/
├── server/
└── client/
```

## Security Rules

- Never commit private keys.
- Never commit production certificates containing private keys.
- Never commit passwords or keystore credentials.
- Keep the CA private key offline or in a secure secrets manager in production.
- Use certificates issued by your organization's trusted CA in production.
- Rotate certificates before expiration.
- Restrict filesystem permissions on private keys and keystores.

## Important

The certificates generated by the local script are intended for development and testing only.

Production deployments should use certificates issued and managed through an organization's PKI or approved certificate-management system.
